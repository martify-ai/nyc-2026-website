# National Youth Convention 2026

A static event website for the National Youth Convention 2026 of Redemption Truth Assembly, themed "Walking with God".

## Overview

This project is a single-page website promoting the convention, featuring:
- Event headline and theme
- Registration call-to-action buttons
- Countdown to the event date
- Event details and highlights
- Gallery images and branding assets

## Project structure

- `index.html` — main website markup and styling
- `images/` — flyer, logo, and gallery assets

## Local preview

Because this is a static site, you can preview it in either of these ways:

1. Open `index.html` directly in a browser.
2. Or run a local web server from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This site is designed to be deployed as a static website on GitHub Pages, Netlify, Vercel, or any basic web host.
